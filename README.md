# BAND NYX — Booking Intelligence

A booking acquisition and event intelligence platform
for Band NYX, a Telugu regional live music band.

## Vision

Help Band NYX grow from 3 to at least 10 paid
bookings per month.

## Target Markets

- Andhra Pradesh
- Telangana
- Bengaluru

## Target Events

- College festivals
- Corporate events
- Private events
- Weddings
- Concerts and cultural events
- Pubs, restaurants and hotels

## Current Features

- Overview dashboard
- Event Radar
- Organiser Intelligence
- Lead Pipeline
- Outreach Centre
- Booking Management
- Revenue Analytics
- Settings

## Technology

- Next.js
- React
- TypeScript
- Tailwind CSS
- Recharts
- Lucide React
